**Project Title:** Offline Student Record System for Sierra Leone  
**Course:** PROG101 - Principles of Programming Logic and Design  

##  Overview
This repository contains the logical design and problem analysis for an **Offline Student Record System**. This project was developed to address community challenges in Sierra Leone's education sector, specifically targeting rural secondary schools that lack reliable internet infrastructure.

*Note: As per assignment requirements, this repository contains logical designs (algorithms, pseudocode, and flowcharts) rather than executable source code.*

##  The Problem Context & Community Impact
Many secondary schools in rural communities across Sierra Leone rely on fragile, manual paper ledgers to track student grades and term statuses. 
* **The Problem:** Manual calculation is time-consuming for teachers and prone to errors, while physical records are vulnerable to loss or damage. Cloud-based solutions are currently unviable due to limited internet connectivity.
* **The Solution:** A localized, offline digital management logic that processes student scores, calculates term totals, and automatically determines final term grades (Pass/Fail) without requiring web connectivity.
* **Beneficiaries:** High school teachers, school administrators, and students in offline communities.

##  Logical Design Features
The system's logic was designed using computational thinking and features:
* **Repetition Structures (Loops):** To iterate through a dynamic number of subjects and calculate a running total score.
* **Decision Structures (IF/ELSE):** To evaluate the final average and assign a term status (e.g., Pass if average >= 50, else Fail).
* **Modular Design & Functions:** Clean separation of input processing, calculations, and final output generation.

##  Sustainable Development Goals (SDGs) & Open Source Justification
* **SDG Alignment (Goal 4 - Quality Education):** By modernizing school administration and ensuring accurate tracking of student performance, this system directly supports equitable and quality education.
* **Open Source:** The logic and future software are designed as Open Source to ensure local tech communities and schools can adopt, modify, and deploy the system without prohibitive licensing fees.
* **Digital Public Goods (DPGs):** This system promotes accessibility and public benefit, serving as a structural framework that local education ministries can freely utilize and localize.
